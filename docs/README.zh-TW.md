## 快速開始

## 開發


安裝相依套件：

```sh
pnpm install
```

開發時執行網頁應用：

```sh
pnpm dev
```

開發時執行桌面應用：

```sh
pnpm tauri:dev
```



建置網頁與桌面目標：

```sh
pnpm build
pnpm tauri:build
```
