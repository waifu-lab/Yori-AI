# Yori AI

[English](https://github.com/waifu-lab/Yori-AI/blob/main/README.md) | [Chinese](https://github.com/waifu-lab/Yori-AI/blob/main/docs/README_zh.md)

Yori AI is a personal AI desktop pet launcher. It cannot run independently and requires the [waifu](https://github.com/waifu-lab/waifu) backend.

## Quick Start

## Development

Install dependencies:

```sh
pnpm install
```

Run the web app during development:

```sh
pnpm dev
```

Run the desktop app during development:

```sh
pnpm tauri:dev
```

Build the web and desktop targets:

```sh
pnpm build
pnpm tauri:build
```
